# Decision Closure

Decision Closure Artifacts are deterministic execution-boundary proof objects for AGS.

They bind the action, authority, decision, conditions, integrity evidence, and audit summary into one third-party-readable artifact. This package does not execute actions, store state, call networks, or claim legal compliance.

v1.7.1 adds deterministic hardening for adversarial public-announcement closure proof failures. An allow decision is not accepted as safe when runtime binding, target-bound approval, receipt proof, meaningful review, and third-party readability are not demonstrated.
